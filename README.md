# Solaris
Solaris is a real-time 3D Solar System simulator developed in Unity, designed to recreate the motion and structure of the planets with scientifically grounded, astronomy-based calculations.
The simulation logic is originally prototyped in Octave/MATLAB, then rewritten in C# to provide accurate elliptical orbits, scale-consistent distances, and continuous real-time movement.

The project features high-quality 3D planet models, physically-inspired lighting for the Sun, and smooth camera navigation through space.
Solaris aims to provide an educational yet visually engaging representation of our Solar System, suitable for demonstrations, interactive exploration, and future expansion with live astronomical data.
